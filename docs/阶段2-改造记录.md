## 二、AI 生成代码发现的问题（人工修复）

1. **日期字符串入库报错**（阶段1遗留）
   - 报错：`SQLite Date type only accepts Python date objects as input`
   - 原因：演示数据把日期写成字符串
   - 修复：`init_data.py` 改为 `date(2023, 5, 10)` 对象

2. **校验错误信息为英文**
   - 现象：422 返回 `Field required` 等英文
   - 修复：全局异常处理器按错误类型翻译为中文，并映射字段中文名

3. **员工/资产字段名冲突**
   - 现象：员工缺失姓名提示「名称不能为空」
   - 修复：`format_validation_error` 根据请求路径区分字段名（由单元测试发现）

4. **CDN 依赖被网络拦截**
   - 现象：页面白屏，jsdelivr 连接被重置
   - 修复：前端库下载到 `static/lib/` 本地引用

- 接口冒烟：统一返回、中文报错、重复拦截、分页筛选、页面访问 → 14/14 通过
