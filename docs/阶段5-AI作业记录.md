## 三、报错与卡点排查记录

### 卡点 1：RAG 检索不精准（查表结构问句命中了代码文件而非表结构文件）

**现象**：提问"员工表 employee 有哪些字段？"时，Top 3 来源是 `routers/ai.py` 而不是 `sql/init.sql` 或 `models/employee.py`。

**AI 分析**：检索用字符二元组重合率打分，问句中的"字段/表"在 `ai.py`（实现表结构查询的代码）中出现密度最高，导致分数高于真正的表结构定义文件；另外切片越小，命中词密度越高，容易放大这种偏差。

**优化方案（已落地）**
1. 检索参数全部配置化（`RAG_CHUNK_SIZE / RAG_CHUNK_OVERLAP / RAG_TOP_K / RAG_MIN_SCORE`），便于调参对比；
2. 项目代码入库使用更大切片（800 字符 / 重叠 100），降低碎片化误命中；
3. 回答附来源文件路径，人工可核对（当前来源已包含 `docs/` 与模型代码，符合预期方向）。

**遗留**：字符重合检索无法理解语义，后续可升级为向量检索（embedding）或加关键词加权。

### 卡点 2：Skill 文件读取的校验顺序（安全加固）

**问题**：初版先判断文件是否存在、再判断扩展名，理论上可用"文件是否存在"的报错差异探测目录结构。

**修复**：调整为 路径沙箱 → 扩展名白名单 → 存在性判断，统一返回模糊错误信息。
```python
if not str(target).startswith(str(root)):
    return {"error": "非法路径：只允许读取项目目录内的文件"}
if target.suffix.lower() not in SKILL_ALLOWED_EXTENSIONS:
    return {"error": f"不支持读取该类型文件：{target.suffix or '（无扩展名）'}"}
if not target.exists() or not target.is_file():
    return {"error": f"文件不存在：{relative}"}
```

### 卡点 3：提示词模板花括号与变量渲染冲突

**问题**：评审 Prompt 的输出格式要求模型返回 JSON（`{"passed": ...}`），但模板渲染用 `str.format`，裸花括号会被当成变量占位符直接报错。

**修复**：JSON 示例统一写成 `{{ }}` 转义；渲染用 `_SafeDict` 容错——未提供的变量保留 `{变量名}` 原样，不抛 KeyError。
```python
class _SafeDict(dict):
    def __missing__(self, key):
        return "{" + key + "}"

template.format_map(_SafeDict(**variables))
```
